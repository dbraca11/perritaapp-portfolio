PerritaApp

App móvil colaborativa para registrar las comidas diarias de una mascota entre varios usuarios en tiempo real. Desarrollada con React Native, Expo y Firebase.

Stack Tecnológico

Frontend

React Native + Expo SDK 57

Lenguaje

TypeScript

Backend

Firebase (Auth, Firestore, Cloud Messaging)

Notificaciones

Expo Notifications + FCM V1

Biometría

Expo Local Authentication + SecureStore

Build & Deploy

EAS Build

Arquitectura de la Aplicación
UI Layer
React Native + Expo Router
Lógica de Negocio
Context API + Hooks
Backend
Firebase Services
